# Прошивка генератора сигнала ESP32-C3 SuperMini

Плата: **ESP32-C3 SuperMini с встроенным OLED 0.42"** (72×40 px).

Полная документация: [docs/esp32-signal-generator.md](../docs/esp32-signal-generator.md)

## Установка

1. Arduino IDE → Менеджер плат → **esp32 by Espressif Systems 3.x**
2. Плата: **ESP32C3 Dev Module**
3. **USB CDC On Boot → Enabled**
4. Менеджер библиотек: **`U8g2`** (by olikraus)

## Подключение

### RC-фильтр (ФНЧ) — пин «1» на плате = GPIO1

```
GPIO1 ──[10 кОм]──┬──► INL + INR (XH-A902, скрутить)
                  │
               [4.7 нФ]
                  │
                 GND
```

### Встроенный OLED (уже на плате)

| Сигнал | GPIO |
|--------|------|
| SDA | GPIO5 |
| SCL | GPIO6 |

**Не используйте GPIO8/GPIO9 для дисплея** — там LED и кнопка BOOT.

## Экран (72×40)

```
RUN ●
50+850 Hz
70/30% 9.0Vpp
T:02:15
```

## Частая ошибка

Если текст смещён вправо и обрезан — в прошивке указаны неверные пины I2C (8/9) или разрешение 128×64 вместо 72×40.

## Подстройка амплитуды

В `.ino` изменить константу `SCALE` (по умолчанию `0.545`).
