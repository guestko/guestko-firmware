# FeelTech FY6300 → оптопара PC817: bench-тест

![Схема: FY6300 → вход оптопары → OUT](signal-generator-wiring.svg)

Воспроизведение сигнала домофона (**50 Гц + 850 Гц**, bipolar AC) на **FeelTech FY6300-60M** и проверка **входного модуля оптопары PC817** (пассивная обвязка, без ESP).

Сигнал генерирует **только FY6300** — прошивки ESP-генератора в репозитории больше нет.

Измерения — **осциллограф** и **мультиметр** (режим DC V).

---

## Целевой сигнал

| Параметр | Значение |
|----------|----------|
| Основная частота | **50 Гц** (sine) |
| Модуляция | **850 Гц** (AM, internal) |
| Форма | Bipolar AC, offset **0 V** |
| Амплитуда | **8 Vpp** (≈ ±4 V) |

## Часть 1. FY6300-60M (без компьютера)

### Настройка CH1

| Параметр | Значение |
|----------|----------|
| Waveform | **Sine** |
| Frequency | **50 Hz** |
| Amplitude | **8.0000 V** |
| Offset | **0 V** |
| Output | **ON** |

### AM-модуляция

| Параметр | Значение |
|----------|----------|
| Mod type | **AM** |
| Mod source | **Internal** |
| Mod frequency | **850 Hz** |
| Mod depth | **30–40 %** (старт **35 %**) |

CH2 может быть **OFF** — для AM используется внутренний генератор модуляции.

### Проверка на осциллографе (до оптопары)

| Настройка | Значение |
|-----------|----------|
| Coupling | **AC** |
| Timebase | **10 ms/div** |
| Vertical | **2 V/div** или **5 V/div** |

**Ожидание:** синус 50 Гц с «толстой» 850 Гц-рябью, Freq ≈ **50 Hz**, Vpp ≈ **6–9 V**.

> AM — быстрый вариант «похоже на эталон». Для **точной** аддитивной смеси `0.7·sin(50t) + 0.3·sin(850t)` используйте раздел ниже.

## Часть 1b. Точная копия с ПК (Arbitrary waveform)

### Вариант A — скрипт fygen (Mac/Linux, рекомендуется)

Скрипт [`scripts/fy6300_play_call_tone.py`](../scripts/fy6300_play_call_tone.py) **сам генерирует** ARB (без CSV в репозитории) и загружает его в **arb1** на FY6300.

Один раз — установка окружения:

```bash
cd guestko-firmware
python3 -m venv .venv-fygen
.venv-fygen/bin/pip install -r scripts/requirements-fygen.txt
git clone https://github.com/mattwach/fygen.git ~/WebstormProjects/fygen
```

**Подключите FY6300 по USB** (нужен драйвер CH340/CH341, если порт не появляется — см. ссылки ниже).

```bash
ls /dev/cu.*   # найти /dev/cu.wchusbserial* или /dev/cu.usbserial*

.venv-fygen/bin/python3 scripts/fy6300_play_call_tone.py \
  --profile e3 \
  --port /dev/cu.wchusbserialXXXX \
  --debug
```

Профили (bitonal sweep, см. PDF Urmet):

| `--profile` | F1 / F2 (Hz) | Sweep (Hz) | Vpp |
|-------------|--------------|------------|-----|
| `a` | 500 / 800 | 11 | 8 |
| `e` | 500 / 820 | 12 | 8 |
| **`e3`** (default) | 500 / 850 | 11 | 8 |
| `v2` | 753 / 841 | 12 | 8 |

Скрипт включает **CH1: arb1**, playback = sweep Hz, **8 Vpp**, offset **0**, **OUT ON**.

Проверка без прибора:

```bash
.venv-fygen/bin/python3 scripts/fy6300_play_call_tone.py --profile e3 --dry-run
```

| Источник | Ссылка |

Обычно в архиве: **USB-драйвер** + **программа управления** + редактор произвольных форм волны. Подключите FY6300 по USB, установите драйвер, затем запустите ПО.

> Если `feeltech.net` недоступен — используйте Yandex-зеркало или диск из комплекта прибора.

Сгенерировать CSV локально (опционально): запустите скрипт с `--dry-run`, затем экспортируйте столбец амплитуд из своего генератора или используйте **Вариант A** выше.

### Загрузка ARB через GUI FeelTech

1. USB → ПК, запустить ПО FeelTech.
2. **CH1** → тип волны **Arbitrary / User / ARB**.
3. **Import / Load** → свой CSV (один столбец амплитуд **−1 … +1**).
4. Если CSV не принимается — вставить столбец в текстовое окно редактора ARB или импортировать как `.txt`.
5. Настройки выхода:

| Параметр | Значение |
|----------|----------|
| Frequency | **sweep Hz** профиля (напр. **11 Hz** для `e3`) |
| Amplitude | **8 Vpp** |
| Offset | **0 V** |
| AM | **OFF** |

6. **Output ON** → проверка на осциллографе (AC, 10 ms/div).

> Для быстрого AM-теста «50 Hz + 850 Hz» без ARB достаточно **Части 1** (Sine + AM 850 Hz). Для сравнения с реальным Urmet используйте **профиль `e3`** через скрипт.

## Часть 2. Входной модуль оптопары (проверенные номиналы)

Схема совпадает с production adapter ([`matter/adapter technical specification`](../matter/adapter%20technical%20specification) §2.2). Номиналы **проверены на стенде** с FY6300 (8 V AM, 50 Hz).

### BOM — вход (LED) PC817

| Ref | Компонент | Номинал | Примечание |
|-----|-----------|---------|------------|
| D1 | Диод **1N4007** | 1 шт. | Полуволновое выпрямление, защита LED |
| C1 | Конденсатор **10 µF** | маркировка **106** | Сглаживание 50 Гц; электролит или керамика X7R ≥16 V |
| U1 | Оптопара **PC817** | — | IN+ = pin 1, IN− = pin 2 |

> **106** на корпусе = **10 µF** (10 × 10⁶ pF в коде EIA). Не путать с **104** (100 nF).

### Схема входа

```
FY6300 SIG ──►| D1      |───┬────► PC817 pin 1 (IN+ / LED anode)
              | 1N4007  |   |
                              |
                           [ C1 10 µF ]
                           маркировка 106
                              |
FY6300 GND ───────────────────┴────► PC817 pin 2 (IN− / LED cathode)
```

**Правила монтажа:**

1. **Анод D1** — к **SIG** (выход FY6300).
2. **Катод D1** — к **pin 1 PC817** и **C1 (+)** (если электролит).
3. **C1 (−)** и **pin 2 PC817** — на **GND** (общая земля с FY6300).
4. **Общая GND** FY6300 и модуля оптопары обязательна.

### Выход PC817 (для измерения на стенде)

| PC817 pin | Подключение |
|-----------|-------------|
| Pin 3 (collector) | **+3.3 V** или **+5 V** (через подтяжку, см. ниже) |
| Pin 4 (emitter) | **GND** |
| Pin 3 → OUT | Внутренний **INPUT_PULLUP** ESP или внешний **10 kΩ** на +3.3 V |

Логика phototransistor: при свете LED pin 3 тянется к GND → **OUT ≈ LOW**.  
На **узле после D1/C1** (pin 1) при сигнале — **стабильный DC ~2.5–2.8 V** (см. ниже).

## Часть 3. Результаты bench-теста (эталон)

Измерено с **1N4007 + 106 (10 µF)** на выходе FY6300 **8 V AM / 50 Hz**:

| Точка | Сигнал ON | Сигнал OFF |
|-------|-----------|------------|
| Узел после D1 / pin 1 PC817 (DMM DC) | **~2.65 V** (2.5–2.8 V) | **< 0.3 V** |
| Ripple на осциллографе (DC coupling) | **~0.3 Vpp** (2.5 V … 2.8 V) | ~0 V |

**Вывод:** ripple **~0.3 V** на фоне **~2.65 V DC** — **не критичен** для детекции «сигнал есть». Минимум **2.5 V** даёт большой запас до порога «нет сигнала» (< 0.5 V).

При необходимости более ровной «полки»: **C1 → 22 µF** (маркировка **226** или 22 µF явно). Для текущего стенда **10 µF (106) достаточно**.

## Часть 4. Проверка приборами

### Мультиметр (DC V)

| Щуп | Сигнал ON | Сигнал OFF |
|-----|-----------|------------|
| **+** на pin 1 PC817 (после D1), **−** на GND | **2.5–2.8 V** | **< 0.3 V** |

### Осциллограф

| Точка | Coupling | Сигнал ON |
|-------|----------|-----------|
| SIG (выход FY6300) | AC | 50 Hz + 850 Hz, ~8 Vpp |
| Pin 1 PC817 (после D1) | DC | DC ~2.65 V, ripple ~0.3 Vpp |

## Чеклист

- [ ] FY6300: **50 Hz**, **AM**, mod **850 Hz**, **8 V**, offset **0**, **OUT ON**

- [ ] **GND общий** FY6300 ↔ модуль оптопары
